Three pages

  • Notes: the reading page. Every idea as a picture story, what the teacher did in class, traps, a cheat sheet and a glossary. No grading.
  • Lesson: one guided problem per idea, all from class. The Concept tab is open first and teaches the idea with different numbers.
  • Practice: all 18 problems from Problem Set 4, plus three challenge problems from class.

The plan

The same seven questions work on every problem this week.

  1. What am I making? Write one.
  2. What is being chosen, and from what?
  3. Different kinds, or a rule? Split into cases, or start with the most restricting part.
  4. Swap two chosen things. Is it a new outcome?
  5. Build it one decision at a time. Same number of options each time? Multiply.
  6. Did I build any outcome more than once? Divide by the copies.
  7. Check a tiny case you can list.

How grading works

Each problem is split into steps, one number per step. He writes his method in the lined box and types the number (or an expression like 12 choose 4 or 2^6 × 11), then presses Check step (Enter in the answer box, Ctrl+Enter in the working box).

A wrong answer gets a nudge, and the nudges get more specific each time. After three misses he gets one final attempt; if that misses too, the step's answer is handed over and he does the next step himself. Hint for this step opens a hint without using a try (it's noted in My steps). Submit question reports how each step went and opens the verified answer and a step-by-step picture story once every step is closed. Show worked answer asks twice if some steps haven't been tried.

Nothing is saved when the tab closes: progress and ink start fresh each visit.

P = pen on/off , Esc = pen off

The teaching pen

Press P (or the ✎ button, bottom right) to write on any page. Four inks, three nibs, a highlighter, straight lines, boxes and an eraser; hold Shift for a straight stroke. Stylus only ignores your palm. On the notes page the ink stays with the text as you scroll and a finger scrolls; on the workbenches the ink stays with each problem. PNG saves the ink only, not the page underneath.
